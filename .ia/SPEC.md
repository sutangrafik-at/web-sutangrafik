# PROYECTO

## Objetivo

Replicar con la máxima fidelidad posible la siguiente web:

https://sutangrafik.wixsite.com/website

El objetivo es obtener una réplica profesional lista para producción.

---

# FUENTE DE VERDAD

La web publicada será la referencia principal durante todo el desarrollo.

Si el usuario proporciona posteriormente:

- Capturas de pantalla.
- Vídeos.
- Recursos originales.

Estos tendrán prioridad sobre cualquier deducción realizada por el agente.

Nunca tomar decisiones de diseño basadas en preferencias personales.

---

# TECNOLOGÍAS

Framework:

- Next.js 15

Lenguaje:

- TypeScript

UI:

- React

Estilos:

- Tailwind CSS

Animaciones:

- Framer Motion (solo cuando sea necesario para replicar el comportamiento original)

Iconografía:

- Lucide React únicamente cuando los iconos originales no puedan recuperarse.

---

# FIDELIDAD

La réplica debe respetar:

- Layout.
- Jerarquía.
- Navegación.
- Orden de las secciones.
- Espaciados.
- Márgenes.
- Paddings.
- Colores.
- Tipografía.
- Imágenes.
- Iconografía.
- Botones.
- Formularios.
- Animaciones.
- Componentes interactivos.
- Responsive.

La implementación puede utilizar tecnologías diferentes a Wix, pero la experiencia del usuario debe ser equivalente.

---

# ELEMENTOS A ELIMINAR

Eliminar únicamente los elementos propios de Wix:

- Banner de Wix.
- Branding de Wix.
- Scripts específicos de Wix.
- Marcas de agua.
- Elementos exclusivos del editor.

Todo lo demás debe mantenerse.

---

# COMPONENTES INTERACTIVOS

Mantener todos los componentes interactivos existentes.

Ejemplos:

- Carruseles.
- Sliders.
- Galerías.
- Lightboxes.
- Tabs.
- Acordeones.
- Formularios.
- Menús desplegables.
- Navegación móvil.
- Animaciones.
- Scroll animations.

Los carruseles deben seguir siendo carruseles.

Nunca sustituir un componente interactivo por otro más simple.

---

# SEO

Implementar:

- Metadata.
- Open Graph.
- Sitemap.
- Robots.
- Etiquetas semánticas.

Sin alterar el contenido original.

---

# RENDIMIENTO

Optimizar:

- Imágenes.
- Fuentes.
- Lazy loading.

Siempre sin modificar el resultado visual.

---

# CRITERIO DE ACEPTACIÓN

El proyecto solo estará finalizado cuando:

- La navegación funcione.
- No existan errores de compilación.
- No existan errores TypeScript.
- No existan errores ESLint.
- La apariencia sea muy similar a la web original.
- El proyecto esté listo para producción.

## Continuidad

El proyecto debe poder continuar en cualquier momento utilizando únicamente la documentación del repositorio y el historial de Git.
